Commands

  • kick / k – Kick a member from the server
  • ban / b – Ban a member from the server
  • mute / m – Mute a member in the server
  • clear / purge – Clear messages from a channel
  • rank – View your current rank and level
  • lb – View the server leaderboard
  • rlevel add – Add a role reward for reaching a level
  • rlevel remove – Remove a role reward
  • rlevel list – List all role rewards
  • rankcard setbg – Set custom rank card background
  • rankcard setcolors – Customize rank card colors
  • meme – Get a random meme
  • 8ball – Ask the magic 8ball a question
  • joke – Get a random joke
  • help – View all available commands
  • serverinfo – Get information about the server
  • userinfo – Get information about a user
  • poll – Create a poll for members to vote on
  • setselfprefix – Set a custom command prefix for yourself
  • partner-list – View all server partners
  • affiliate-list – View all server affiliates
  • addshopitem – Add a new item to the server shop
  • editshopitem – Edit an existing shop item
  • removeshopitem – Remove an item from the shop
